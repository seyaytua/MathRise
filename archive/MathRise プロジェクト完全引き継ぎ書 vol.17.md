## 目的

## 重要度判定の基準

| 重要度 | 特徴 | 学習時間 | 例 |
|--------|------|----------|-----|

以下のいずれかに該当する場合、「山場」と判定：

1. **新しい重要概念の導入**

2. **複数の概念の統合**
   - 例: 平方完成を使った最大値・最小値

3. **つまずきやすいポイント**
   - 例: 符号の扱い、場合分け

## 目的
指定されたレッスンの詳細な教材を生成する。

## 入力情報

## 生成ルール

### 1. 数学的正確性の保証 ⭐ 最優先

**必須チェック項目**:
- [ ] 定義が教科書と完全に一致する
- [ ] 計算結果が正しい
- [ ] グラフの形状が正しい
- [ ] 符号（正・負）が正しい

**特に注意すべき項目**:
- 二次関数の凸性：`a > 0` → 下に凸、`a < 0` → 上に凸
- 最大値・最小値：凸性と対応する
- 符号の扱い：マイナスの扱いに注意

**検証方法**:
1. 生成後、必ず複数の教科書で確認
2. 別の方法で計算し、結果を照合
3. グラフを実際に描いて確認

### 2. 「行間を埋める」の実現

教科書が省略している箇所を特定し、段階的な問いに変換する。

**省略パターン**:

| 教科書の表現 | 省略されている内容 | 問いに変換 |
|--------------|-------------------|------------|
| 「明らかに」 | 計算過程、論理的推論 | 「なぜそうなるか、計算してみましょう」 |
| 「したがって」 | 中間ステップ | 「次のステップは何でしょうか」 |
| 「容易にわかる」 | 前提知識の適用 | 「どの知識を使えばよいでしょうか」 |

### 3. step-by-step問題の設計

**基本構造**:
- ステップ数: 3-5個（多すぎない）
- 各ステップ: 1つの明確な問い
- 最後のステップ: 答えの確認

**重要な学び（vol.16）**:

#### ⚠️ 入力が1つだと先に進まない問題

**問題**:
- 選択肢問題で「上に凸」と入力しても、システムは「1」を期待している
- ユーザーが正しい答えを入力しているのに、不正解になる

**解決策: 入力緩和機能**:

```json

  "answer": "1",
  "answerType": "number",
  "type": "number"
}
ポイント:

プロンプトに「1 または 2 の数字を入力してください」と明記
システム側で入力を正規化（「上に凸」→「1」に変換）

import json
import re

def check_quadratic_function(lesson):
    """二次関数の凸性をチェック"""
    errors = []
    
    for problem in lesson['problems']:
        for step in problem.get('steps', []):
            prompt = step.get('prompt', '')
            answer = step.get('answer', '')
            
            # a < 0 の場合をチェック
            if 'a < 0' in prompt or 'a<0' in prompt or 'a = -' in prompt:
                if '下に凸' in answer or answer == '2':
                    errors.append({
                        'problem': problem['problemId'],
                        'step': step['stepId'],
                        'error': 'a < 0 のとき「下に凸」は誤り。正しくは「上に凸」'
                    })
            
            # a > 0 の場合をチェック
            if 'a > 0' in prompt or 'a>0' in prompt:
                if '上に凸' in answer or answer == '1':
                    errors.append({
                        'problem': problem['problemId'],
                        'step': step['stepId'],
                        'error': 'a > 0 のとき「上に凸」は誤り。正しくは「下に凸」'
                    })
    
    return errors

def check_input_flexibility(lesson):
    """入力の多様性をチェック"""
    warnings = []
    
    for problem in lesson['problems']:
        for step in problem.get('steps', []):
            prompt = step.get('prompt', '')
            
            # 選択肢問題で入力方法が明記されているかチェック
            if '選択肢' in prompt:
                if '数字を入力' not in prompt and '番号を入力' not in prompt:
                    warnings.append({
                        'problem': problem['problemId'],
                        'step': step['stepId'],
                        'warning': '選択肢問題で入力方法が明記されていません'
                    })
    
    return warnings

def main():
    with open('courses/math-1-sample.json', encoding='utf-8') as f:
        data = json.load(f)
    
    for unit in data['units']:
        for lesson in unit['lessons']:
            print(f"\n{'='*60}")
            print(f"{lesson['id']}: {lesson['title']}")
            print('='*60)
            
            # 数学的正確性のチェック
            errors = check_quadratic_function(lesson)
            if errors:
                print("\n❌ 数学的正確性の問題:")
                for error in errors:
                    print(f"   問題: {error['problem']}, ステップ: {error['step']}")
                    print(f"   エラー: {error['error']}")
            else:
                print("\n✅ 数学的正確性: OK")
            
            # 入力の多様性のチェック
            warnings = check_input_flexibility(lesson)
            if warnings:
                print("\n⚠️ 入力の多様性の警告:")
                for warning in warnings:
                    print(f"   問題: {warning['problem']}, ステップ: {warning['step']}")
                    print(f"   警告: {warning['warning']}")
            else:
                print("✅ 入力の多様性: OK")
