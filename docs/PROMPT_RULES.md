# プロンプトルール

## 🎯 このドキュメントの目的

プロンプトの調整において、何を変更してよいか、何を変更してはいけないかを明確にする。

**参照**: [CORE_CONCEPTS.md](CORE_CONCEPTS.md) - 基本コンセプトの詳細

---

## 🔴 絶対に変更してはいけないもの

### 1. 基本コンセプト（3つの設計原則）

✗ 「行間を埋める学習」を削除する ✗ 「メリハリのある学習設計」を削除する ✗ 「AI進化への対応」を削除する


**理由**: これらはMathRiseの核心であり、削除すると別のアプリになる

---

### 2. 重要度3段階（低/中/高）

✗ 重要度を2段階にする ✗ 重要度を4段階にする ✗ 重要度の区分を廃止する


**理由**: メリハリのある学習設計の基盤

**ただし調整可能**:
- ✓ 判定基準の明確化
- ✓ 推定時間の微調整（±2分程度）

---

### 3. 山場の存在

✗ 山場を全て削除する ✗ 山場を低重要度にする ✗ 山場の判定条件を無視する


**理由**: 深い学びを実現するための核心

**ただし調整可能**:
- ✓ 山場の数（30-40%の範囲内）
- ✓ 山場の前に基礎固めレッスンを追加

---

### 4. step-by-step形式

✗ step-by-step形式を廃止する ✗ 全ての問題を一問一答にする


**理由**: 行間を埋める学習の実現方法

**ただし調整可能**:
- ✓ ステップ数（3-5ステップの範囲内）
- ✓ 各ステップの問いの表現

---

## 🟡 条件付きで変更できるもの

### 1. 説明文の長さ

**変更可能な範囲**:
- 低重要度: 200-400字 → 150-450字（±50字）
- 中重要度: 400-600字 → 350-650字（±50字）
- 高重要度: 600-800字 → 550-850字（±50字）

**条件**:
- 重要度に応じた長さの比率を維持
- 基本コンセプトの説明は削除しない

**例**:
✓ 高重要度を650字にする（範囲内） ✗ 高重要度を400字にする（中重要度と同じになる）


---

### 2. 具体例の数

**変更可能な範囲**:
- 低重要度: 0-1個
- 中重要度: 1-2個
- 高重要度: 2-3個

**条件**:
- 重要度が高いほど多くする
- 具体例は必ず関連性のあるものを選ぶ

**例**:
✓ 高重要度に具体例を3個追加する ✗ 低重要度に具体例を5個追加する


---

### 3. レッスンの数

**追加可能なレッスン**:
- 山場の前：基礎固めレッスン（低重要度）
- 単元の最後：復習レッスン（中重要度）

**条件**:
- 山場の数は維持（30-40%）
- 追加レッスンは最大で全体の10%まで

**例**:
✓ 平方完成（山場）の前に「展開と因数分解の復習」を追加 ✗ 山場を削除して基礎レッスンに置き換える


---

### 4. ヒントの数

**変更可能な範囲**:
- 1-3個

**条件**:
- 段階的なヒント（軽い→詳細）を維持
- 最後のヒントでも答えは直接示さない

**例**:
✓ ヒントを3段階にする ✗ ヒントで答えを直接示す


---

## 🟢 自由に変更できるもの

### 1. 言い回し

**変更可能**:
- より分かりやすい表現
- より正確な数学用語
- より親しみやすい表現

**例**:
変更前: 「平方完成を行う」 変更後: 「平方完成の形に変形する」


---

### 2. 例題の選択

**変更可能**:
- より適切な例題
- より身近な例題
- より興味深い例題

**条件**:
- 数学的に正確であること
- 学習目標に関連すること

---

### 3. ヒントの表現

**変更可能**:
- より分かりやすいヒント
- より段階的なヒント
- より視覚的なヒント

**条件**:
- 答えを直接示さないこと
- 考える余地を残すこと

---

## 📋 調整パターン

### パターン1: 基礎固めの追加

**要望**: 「山場の前に基礎固めの時間がほしい」

**判定**:
- ✓ 基本コンセプトを崩さない
- ✓ 山場は維持
- ✓ レッスン追加は条件内

**調整内容**:
```json
{
  "action": "prerequisite_review レッスンを追加",
  "config": {
    "importance": "low",
    "estimated_time": 5,
    "insert_position": "before_peak"
  }
}
結果: ✅ 対応可能

パターン2: 具体例の増加
要望: 「具体例をもっと増やしてほしい」

判定:

✓ 基本コンセプトを崩さない
✓ 条件付きで変更可能
調整内容:

Copy{
  "action": "examples の数を調整",
  "config": {
    "high_importance": 3
  }
}
結果: ✅ 対応可能

パターン3: 山場の削除
要望: 「山場を全部なくしてほしい」

判定:

✗ 基本コンセプトに反する
✗ メリハリのある学習設計が崩れる
調整内容: なし

結果: ❌ 対応不可

代替案:

山場の前に基礎固めレッスンを追加
