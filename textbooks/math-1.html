多項式の基本用語と整理

高重要度 ⏱ 15分

所属トピック

第1章 数と式 - 第1節 展開と因数分解

多項式とは

多項式とは、文字を含む式のうち、項の和として表される式のことです。例えば、$$3x^2 + 2x - 5$$ は多項式です。この式は3つの項（$$3x^2$$、$$2x$$、$$-5$$）から成り立っています。

各項は、数（係数）と文字の積で表されます。$$3x^2$$ では、3が係数、$$x^2$$ が文字の部分です。

基本用語

項（こう）： 多項式を構成する、加法記号（+）または減法記号（-）で区切られた各部分を項といいます。

係数（けいすう）： 各項において、文字にかかっている数を係数といいます。$$5x$$ の係数は5です。

定数項（ていすうこう）： 文字を含まない項を定数項といいます。$$3x^2 + 2x - 5$$ の定数項は -5 です。

次数（じすう）： 各項において、文字の指数の和を次数といいます。$$3x^2$$ の次数は2です。

多項式の整理

多項式を整理するとは、同類項をまとめて、次数の高い順（降べきの順）または低い順（昇べきの順）に並べることです。

例：$$2x + 5x^2 - 3 + x^2 - x$$ を整理すると、$$6x^2 + x - 3$$ となります。

展開の公式（基本）

高重要度 ⏱ 20分

所属トピック

第1章 数と式 - 第1節 展開と因数分解

展開とは

展開とは、括弧を外して式を書き直すことです。例えば、$$(x + 2)(x + 3)$$ を展開すると $$x^2 + 5x + 6$$ となります。

基本の展開公式

公式1： $$(a + b)^2 = a^2 + 2ab + b^2$$

公式2： $$(a - b)^2 = a^2 - 2ab + b^2$$

公式3： $$(a + b)(a - b) = a^2 - b^2$$

公式4： $$(x + a)(x + b) = x^2 + (a + b)x + ab$$

公式の使い方

例1：$$(x + 3)^2$$ を展開する

公式1を使って、$$a = x$$、$$b = 3$$ とすると、

$$(x + 3)^2 = x^2 + 2 \cdot x \cdot 3 + 3^2 = x^2 + 6x + 9$$

例2：$$(x + 2)(x - 2)$$ を展開する

公式3を使って、$$a = x$$、$$b = 2$$ とすると、

$$(x + 2)(x - 2) = x^2 - 2^2 = x^2 - 4$$

因数分解の基本

高重要度 ⏱ 18分

所属トピック

第1章 数と式 - 第1節 展開と因数分解

因数分解とは

因数分解とは、多項式を積の形に変形することです。展開の逆の操作です。例えば、$$x^2 + 5x + 6$$ を因数分解すると $$(x + 2)(x + 3)$$ となります。

基本の因数分解公式

公式1： $$a^2 + 2ab + b^2 = (a + b)^2$$

公式2： $$a^2 - 2ab + b^2 = (a - b)^2$$

公式3： $$a^2 - b^2 = (a + b)(a - b)$$

公式4： $$x^2 + (a + b)x + ab = (x + a)(x + b)$$

因数分解の手順

1. 共通因数があれば、まず括り出す

2. 項数を確認する（2項、3項、4項以上）

3. 適切な公式を選んで適用する

4. 因数分解できなくなるまで続ける

二次関数のグラフ

高重要度 ⏱ 25分

所属トピック

第2章 二次関数 - 第1節 二次関数とグラフ

二次関数とは

二次関数とは、$$y = ax^2 + bx + c$$ の形で表される関数です。$$a \neq 0$$ という条件があります。

二次関数のグラフは放物線と呼ばれる曲線になります。

基本形 $$y = ax^2$$

最も基本的な二次関数 $$y = ax^2$$ のグラフは、原点を頂点とする放物線です。

$$a > 0$$ のとき：下に凸の放物線（上に開く）

$$a < 0$$ のとき：上に凸の放物線（下に開く）

$$|a|$$ が大きいほど、グラフは細くなります。

平行移動

$$y = a(x - p)^2 + q$$ の形は、$$y = ax^2$$ のグラフを

・$$x$$ 軸方向に $$p$$ だけ平行移動

・$$y$$ 軸方向に $$q$$ だけ平行移動

したものです。頂点の座標は $$(p, q)$$ となります。

二次関数の最大値・最小値

高重要度 ⏱ 22分

所属トピック

第2章 二次関数 - 第2節 二次関数の最大・最小

最大値・最小値とは

関数 $$y = f(x)$$ において、$$y$$ の値が最も大きくなるときの値を最大値、最も小さくなるときの値を最小値といいます。

二次関数の最大値・最小値

二次関数 $$y = a(x - p)^2 + q$$ において、

$$a > 0$$ のとき：$$x = p$$ で最小値 $$q$$ をとる（最大値なし）

$$a < 0$$ のとき：$$x = p$$ で最大値 $$q$$ をとる（最小値なし）

定義域が制限されている場合

$$a \leq x \leq b$$ のように定義域が制限されている場合は、

1. 頂点が定義域に含まれるか確認

2. 含まれる場合：頂点で最大値または最小値

3. 含まれない場合：端点で最大値・最小値を調べる
